# Typewarts

**Твоя клавиатура — волшебная палочка. Каждое слово — заклинание.**

Поздняя ночь, недописанный код и обещание закрыть глаза всего на пять минут. Вместо отдыха — школа магии, встреча с призраком и дуэль, в которой всё решают твои пальцы.

Typewarts — сюжетная браузерная игра для тренировки печати на русском. Набирай заклинания, отражай атаки и пробивайся через зачарованные коридоры. Здесь скорость помогает успеть, а точность делает магию сильнее.

## Магия начинается с первой буквы

- **История в комиксах.** Иллюстрированные сцены, диалоги и герой, который совсем не планировал становиться волшебником.
- **Дуэли на клавиатуре.** Атакуй и защищайся, набирая заклинания до конца отсчёта. Каждое завершённое слово превращается в удар или щит.
- **Два испытания.** Освой короткие заклинания в бою с призраком, затем встреться со стражем коридора: формулы станут длиннее, а времени на раздумья — меньше.
- **Точность даёт силу.** Слова без ошибок усиливают атаки, а серии удачных заклинаний открывают мощные комбо.
- **Подсказки под рукой.** Экранная клавиатура подсвечивает следующую клавишу, а счётчики показывают скорость, точность и серию.
- **Прогресс остаётся с тобой.** Пройденные уроки, опыт и рекорд скорости сохраняются в браузере. Можно вернуться и попробовать ещё лучше.

В книге заклинаний — двадцать знакомых формул. В дуэли — живописные декорации, вспышки магии и противник, который не станет ждать, пока ты найдёшь нужную букву.

## Как играть

Понадобятся компьютер, физическая клавиатура и русская раскладка. Перед первой дуэлью игра познакомит с управлением.

| Действие | Управление |
| --- | --- |
| Продолжить историю | `Enter`, `→`, пробел или кнопка на экране |
| Вернуться к предыдущему кадру | `←` |
| Начать дуэль | `Enter` или «Начать дуэль» |
| Атаковать или поставить щит | Набрать подсвеченное заклинание |
| Открыть паузу | `Esc` или кнопка `Ⅱ` |

Ошибся? Продолжай с подсвеченной буквы — стирать ничего не нужно. Пробелы в длинных заклинаниях тоже считаются. В меню паузы можно повторить обучение, перечитать историю или открыть книгу заклинаний.

## Запустить у себя

Установи Node.js с npm, затем выполни в каталоге проекта:

```sh
npm install
npm run dev
```

Открой адрес, который покажет Vite, переключись на русскую раскладку — и приготовься к первой дуэли.

```sh
npm run build   # Собрать игру в dist/
npm run preview # Открыть собранную версию локально
npm test        # Проверить игровые правила и сохранения
```

## Под капотом

TypeScript, Phaser 3, React и Vite. Phaser рисует игровой мир и интерфейс в одном canvas, React отвечает за контейнер приложения. Сцена масштабируется под окно, сохраняя пропорции графики; базовая композиция — 1600 × 900.

Код разделён по назначению:

| Каталог | Что внутри |
| --- | --- |
| `src/content` | Сюжет, уроки, заклинания и каталог изображений |
| `src/domain` | Правила боя, прогресс и метрики печати |
| `src/scenes` | Загрузка ресурсов и управление игрой |
| `src/views` | Комикс, экран боя и эффекты заклинаний |
| `src/ui` | Меню, обучение, кнопки и клавиатура |
| `src/runtime` | Запуск Phaser и масштабирование |
| `src/tests` | Тесты правил, сохранений и размещения реплик |
| `public/assets` | Графические ресурсы |

Правила игры не зависят от движка и проверяются отдельно. Серверная часть и регистрация не нужны: прогресс хранится локально в браузере. Незавершённая дуэль не сохраняется.

Typewarts — фан-проект в разработке. Текущая версия рассчитана на игру за компьютером.
