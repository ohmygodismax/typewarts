# Typewarts

Локальный фан-прототип обучения печати на русском. React + TypeScript + Phaser 3. Без звуков и серверной части.

## Запуск

```sh
npm install
npm run dev
```

Открыть адрес, который напечатает Vite. Нужна физическая клавиатура с русской раскладкой. `npm run build` собирает приложение в `dist`, `npm test` проверяет правила боя и сохранение данных. Автоматического деплоя нет.

## Что работает

- Весь видимый интерфейс рисует Phaser: прелоадер, комикс, кнопки, бой и клавиатура. React только создаёт контейнер canvas.
- Прелоадер показывает реальную загрузку изображений и автоматически переходит дальше.
- Клавиатура всегда находится под зоной дуэли внутри того же canvas. Enter начинает урок, Escape открывает паузу.

- Девять кадров комикса с постепенным раскрытием реплик: клик или Enter показывают следующую реплику, затем следующий кадр. Стрелка влево возвращает предыдущий кадр. Повтор вступления — пауза → «История».
- Живописная сцена Phaser: персонажи, парение призрака, свет, частицы, удары и ответные атаки.
- Пять последовательных уроков и двадцать заклинаний. Атака и защита чередуются; в первых уроках больше времени на ввод.
- Подсказки русских клавиш и пальцев, точность, скорость и серия.
- Чистое заклинание имеет 125% силы, исправленное после ошибки — 65%, каждое десятое чистое упражнение — 180%.
- В дуэлях нужно закончить упражнения и победить противника; при необходимости повторяется последнее заклинание.
- Пауза, автоматическая пауза при потере фокуса, победа и поражение, повтор урока.
- Пройденные уроки, опыт и рекорд скорости сохраняются в localStorage (`typewarts-v1`). Текущая незаконченная дуэль не сохраняется.

## Графика и оставшаяся работа

Готовые изображения: класс, герой, призрак, работа за компьютером до сна, сон за компьютером, «Отказ не принят». Генерация изображений согласована пользователем. Изображения находятся в `public/assets`. Лист из четырёх кадров не используется.

Пробуждение, распределение со Шляпой, отказ и поднятие клавиатуры имеют отдельные иллюстрации. Исходный герой используется как образец внешности. Финальная сцена вызова пока собрана из фона и персонажей. Корпус клавиатуры, клавиши и деревянный стол — отдельные рисованные ассеты; надписи рисует Phaser для чёткости. Промпты сохранены рядом с изображениями.

Анимация героя сейчас — движение цельного изображения, не покадровая анимация тела. Финальный противник пока использует затемнённый вариант призрака. Баланс уроков требует проверки с начинающими пользователями.

OpenMoji и фотография замка из ранней версии сохранены, но текущим экраном не используются. Интерфейс рисует Phaser, используются системные шрифты. Сгенерированные ассеты не дают прав на коммерческое использование чужой литературной вселенной.

Композиция фиксирована: 1600 × 900, без мобильной адаптации. При изменении окна масштабируется весь canvas с сохранением пропорций.
